Phish or Treat 

A Halloween-themed cybersecurity web app built with FastAPI. Users can interact with the app to guess and learn about phishing tactics in a safe environment.

Features
Interactive "Phish or Treat" guessing game
Tracks user score
Uses FastAPI backend and Jinja2 templates for dynamic web pages

How to Run Locally
1. Clone the repo:
   ```bash
   git clone https://github.com/AstatineXeon/phish-or-treat.git

2. Install dependencies:
pip install -r requirements.txt

3. Run the server
uvicorn main:app --reload

4. Open in browser: http://127.0.0.1:8000

How It Works

-User visits the site.

-User guesses if a link is a phishing attempt.

-The app tracks correct guesses and provides feedback.

-Safe, interactive way to learn about phishing attacks.
